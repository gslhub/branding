This repository contains the approved visual identity assets and usage guidance for **GSLHub — Generative Search Lab Hub**.

GSLHub is an independent applied-research initiative focused on Generative Search, Generative Engine Optimization (GEO), AI-system evaluation, governed evidence and reproducible research.

| `assets/gslhub-logo.svg` | Primary horizontal logo for light backgrounds |
| `assets/gslhub-logo-dark.svg` | Horizontal logo for dark backgrounds |

Additional export formats may be added under `exports/` when required.

## Brand principles

The GSLHub identity should communicate:

- **research rigor** — evidence, methodology and reproducibility;
- **technology** — AI systems, software engineering and structured experimentation;
- **openness** — inspectable research infrastructure and transparent methodology;
- **clarity** — minimal visual noise and strong information hierarchy.
