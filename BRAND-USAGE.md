# GSLHub Brand Usage

The GSLHub name, logos, icons, wordmarks and other brand identifiers are separate from the open-source license applied to GSLHub software.

## Software vs. brand

That software license does **not** grant permission to present modified software, derivative projects, commercial services or third-party research as official GSLHub work by using GSLHub names or visual identifiers.

## Permitted reference use

You may use the GSLHub name and approved visual assets when reasonably necessary to:

- identify or link to the official GSLHub project;
- reference GSLHub in academic, technical, journalistic or educational material;
- describe factual compatibility with, use of, or contribution to GSLHub;
- reproduce an official GSLHub research output with appropriate attribution where its own license permits this.

Such use must not imply sponsorship, endorsement, partnership or official status when none exists.

## Permission required

Please request permission before using GSLHub branding for:

- a product, service or company name;
- a domain name or social account that could appear official;
- merchandise or commercial promotion;
- a modified or derivative logo;
- co-branding that implies an organizational partnership;
- a redistributed or modified version of GSLHub presented as the official project.
