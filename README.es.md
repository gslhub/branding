Este repositorio contiene los activos aprobados de identidad visual y las guías de uso de **GSLHub — Generative Search Lab Hub**.

GSLHub es una iniciativa independiente de investigación aplicada centrada en Búsqueda Generativa, Generative Engine Optimization (GEO), evaluación de sistemas de IA, evidencia gobernada e investigación reproducible.

## Principios de marca

La identidad de GSLHub debe comunicar:

- **rigor científico** — evidencia, metodología y reproducibilidad;
- **tecnología** — sistemas de IA, ingeniería de software y experimentación estructurada;
- **apertura** — infraestructura de investigación inspeccionable y metodología transparente;
- **claridad** — mínimo ruido visual y una jerarquía fuerte de información.
